# UrbanStyle PH – Local Brand Marketplace

A single-page storefront for local brand shoes, sandals and bags.

- `index.html` – the whole site (HTML, CSS and JavaScript in one file)

## Features
- Featured products slideshow (5 at a time, click arrows)
- Category filters and product view with "Add to basket"
- Basket drawer with peso prices
- Light and dark mode, mobile friendly

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.

Products, brands and prices are placeholders.
